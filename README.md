<summary><b>⚙️ Snake Animation Setup (click to expand)</b></summary>

### Step 1 — Create the workflow file

In your profile repo (`harshu078600-tech/harshu078600-tech`), create:

**`.github/workflows/snake.yml`**

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"  # runs every day at midnight UTC
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Step 2 — Run it manually once

Go to **Actions tab → Generate Snake → Run workflow**

After it runs, the snake SVGs will be in the `output` branch of your repo and the animation will appear live on your profile.
